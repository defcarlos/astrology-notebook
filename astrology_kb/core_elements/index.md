# Core Astrological Elements

This directory contains the primary variables used in chart analysis. An autonomous agent or astrologer must synthesize these elements to understand the static promise of a natal chart.

## Element Categories

* **[Planets (Grahas)](planets/index.md)**: The energetic agents that "grab" consciousness, including the luminaries, the five visible planets, and the lunar nodes.
* **[Signs & Zodiac (Rashis)](signs_and_zodiac/index.md)**: The 12 psychological and elemental environments through which the planets filter their energy.
* **[Houses (Bhavas)](houses_bhavas/index.md)**: The 12 specific domains of human life (e.g., identity, wealth, partnership, career).
* **[Nakshatras (Lunar Mansions)](nakshatras/index.md)**: The 27 stellar divisions of the zodiac, critical for deep psychological profiling and timing (Dasha) calculations.
* **[Divisional Charts (Vargas)](vargas_divisional_charts.md)**: Harmonic micro-divisions (D-9 Navamsa, D-10 Dashamsha) verifying inner soul resilience, marriage dynamics, career archetypes, and Vargottama dignity.
